# 매일 운영 순서

[문서 목록](README.md) · [상세 사용 설명서](user-guide.md) · [SNS 게시](social-channels.md)

## 1. 앱 열기

1. Windows 탐색기에서 `C:\dev\dev\d2c\codex_version\start.bat`을 실행합니다. SNS 로그인·게시를 사용할 날에는 Codex의 제한된 터미널에서 서버를 시작하지 않습니다.
2. 자동으로 열리지 않으면 [http://127.0.0.1:4317](http://127.0.0.1:4317)을 엽니다.
3. 첫 화면 **오늘 할 일**의 상단 안내를 읽습니다.

저장된 데이터와 로그인 프로필은 재부팅해도 유지됩니다. `npm install`, 네이버 키 입력, SNS 로그인을 매번 반복하지 않습니다. 다만 네이버가 보는 공인 IP가 바뀌거나 SNS 세션이 만료되면 해당 연결만 다시 확인합니다.

## 2. 남은 게시 기록 먼저 마치기

**게시물 주소를 기록하세요** 또는 **게시 완료 · 주소 기록 필요**가 보이면 같은 채널에 다시 게시하지 않습니다.

1. 실제 Instagram·Threads·밴드에서 방금 게시된 글을 엽니다.
2. 주소창의 실제 게시물 URL을 복사합니다.
3. 앱의 해당 채널 주소 칸에 붙여넣습니다.
4. 실제 게시 확인란을 체크하고 **주소 기록**을 누릅니다.

캠페인은 선택한 모든 채널의 주소를 기록할 때까지 **게시 준비**로 남습니다. 일부 채널만 게시하고 마칠 계획으로 바뀌었다면 게시 전 캠페인의 채널 선택을 수정하고 다시 검토합니다. 이미 한 채널의 게시 기록이 생긴 뒤에는 확정 콘텐츠를 수정할 수 없습니다.

## 3. 네이버 상품과 주문 수집

**오늘 할 일 → 스토어 수집**에서 실행합니다.

- 여러 스토어를 한 번에 갱신: **전체 수집**
- 한 스토어만 갱신: 해당 스토어 행의 **수집**
- 상품만 필요: **상품 보관함 → 네이버 상품 수집**
- 주문만 필요: **주문 · 수집 기록 → 주문 수집**

상품과 주문 화면의 스토어 필터로 결과를 구분합니다. 이동 중 핫스팟·Wi-Fi·VPN을 바꿨다면 각 네이버 애플리케이션에 현재 공인 IP가 등록돼 있는지 확인합니다. 전체 수집에서 한 스토어가 실패해도 다른 스토어 결과와 실패 수를 함께 표시합니다.

## 4. 동향에서 광고 아이디어 찾기

선택 사항입니다. 최근 화제를 광고 소재에 참고할 날에 실행합니다.

1. **오늘 할 일 → 최근 동향에서 광고 기회 찾기**로 이동합니다.
2. **오늘의 화제 조사**, **이번 주 화제 조사**를 누르거나 키워드를 입력합니다.
3. 처음 사용하는 PC라면 **연결 · 채널 → ChatGPT로 Codex 로그인**을 완료합니다.
4. 조사 버튼을 누르면 AI가 시작됩니다. 기존 대기 요청은 **AI 조사 시작**을 누릅니다.
5. 출처, 발행일, 활용 기간과 주의 사항을 확인합니다.
6. 적합한 결과의 **이 아이디어로 캠페인 만들기**를 누릅니다.

AI 연결 상태에서는 요청 저장과 조사가 연속 실행됩니다. 조사 결과는 일반 뉴스 목록이 아니라 현재 판매 중인 상품과 연결할 수 있는 근거와 광고 방향으로 저장됩니다.

## 5. 새 캠페인 만들기

1. **상품 보관함**에서 판매 중인 상품을 찾습니다.
2. 필요하면 스토어 필터로 범위를 좁힙니다.
3. **이 상품으로 캠페인 만들기**를 누릅니다.
4. 로그인 완료로 활성화된 Instagram·Threads·네이버 밴드 중 게시할 채널을 선택합니다.
5. 제목과 제작 방향을 입력해 캠페인을 만듭니다.

Threads도 선택했다면 최종 본문은 500자 이하여야 합니다. 밴드를 선택했다면 게시 전에 **연결 · 채널**에서 대상 밴드 홈 주소를 저장합니다.

## 6. Codex로 카피와 이미지 만들기

1. 캠페인에서 **AI 광고 제작 시작**을 누릅니다.
2. 화면 상단의 생성·렌더링·저장 상태를 확인합니다.
3. 완료되면 카피 시안, 본문, 게시 이미지를 확인합니다.
4. 수정했다면 **수정 내용 저장**을 누릅니다.

처음 한 번은 [구독 Codex AI 연결](ai-automation.md)을 완료해야 합니다. 로그인 전 요청은 영속적으로 보관되며 오늘 할 일 화면에서 나중에 실행할 수 있습니다.

## 7. 검토

1. 가격, 구성, 원산지, 포장, 배송·할인 조건을 실제 상품과 대조합니다.
2. 이미지에 상품과 다른 표현이 없는지 확인합니다.
3. 선택한 채널과 본문 길이를 확인합니다.
4. 사실 확인란을 체크하고 **검토 완료로 표시**를 누릅니다.

검토 전에는 채널을 바꿀 수 있습니다. 검토 후 내용을 수정하면 다시 제작 중으로 돌아가며 재검토해야 합니다.

## 8. SNS별 게시

선택한 채널마다 아래 순서를 반복합니다.

1. 상태가 **로그인 필요**이면 **로그인 열기**를 누르고 전용 브라우저에서 직접 로그인합니다.
2. 게시 계정, 이미지, 본문, 밴드 대상 홈을 확인합니다.
3. 즉시 게시 확인란을 체크합니다.
4. 채널의 **게시** 버튼을 누릅니다.
5. 게시 중에는 같은 버튼을 다시 누르지 않습니다.
6. 완료 후 실제 게시물을 확인하고 URL을 기록합니다.

Instagram은 기존 `data/instagram-profile`을 계속 사용합니다. Threads는 `data/threads-profile`, 밴드는 `data/band-profile`을 사용합니다. 세 프로필은 서로 로그인 정보를 복사하지 않습니다.

## 9. 종료와 백업

1. 미저장 편집이 없는지 확인합니다.
2. **주문 · 수집 기록**에서 마지막 수집 결과를 확인합니다.
3. 필요하면 **연결 · 채널 → DB 백업 만들기**를 실행합니다.
4. `stop.bat`을 실행합니다.

브라우저 탭만 닫으면 서버는 계속 실행될 수 있습니다. 이미지까지 보존하려면 `data/assets`를 포함한 `data` 폴더 전체를 백업합니다.

## 점검이나 예외 상황에 쓰는 Codex 요청

> codex_version을 실행하고 모든 네이버 스토어의 상품과 주문을 수집한 뒤 실패한 연결과 오늘 할 일을 알려줘.

> codex_version의 최근 네이버 수집과 SNS Playwright 상태를 확인해줘. 키와 쿠키는 출력하지 마.
