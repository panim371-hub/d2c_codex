- 상품·주문 페이지, 체크포인트, 멱등성, 네트워크 오류 처리

운영 서버를 0.5.0으로 재시작한 뒤 실제 DB와 브라우저에서 다음을 확인했습니다.

- **오늘 할 일**의 핵심 지표, 동향 레이더 빈 상태, 실제 작업 목록, 스토어·SNS 상태가 가로 넘침 없이 정상 렌더링됨

## 실서비스 검증 상태

| 항목 | 상태 |
|---|---|
| 네이버 상품 실제 수집 | 2026-09-05에 8개 성공 |
| 네이버 주문 0건 구간 | 실제 빈 응답 처리 성공 |
| 네이버 주문이 있는 구간 | fixture만 검증, 실주문 응답 대기 |
| Instagram 로그인·게시 | 실제 로그인, 이미지, 본문, 공유 완료 메시지 검증 |
| Instagram 실제 URL 기록 | 첫 캠페인의 `/p/…/` 실제 URL이 publication으로 기록됨 |
| Threads 로그인·게시 | 코드·상태/API 테스트 완료, 실계정 검증 전 |
| 네이버 밴드 로그인·게시 | 코드·설정/API 테스트 완료, 실계정과 대상 밴드 검증 전 |
| 여러 네이버 스토어 동시 실수집 | 조정 테스트 완료, 두 번째 실제 키 연결 전 |

Threads와 밴드는 실제 계정의 화면 언어, 보안 확인, 권한에 따라 선택자 보완이 필요할 수 있습니다. 앱은 성공을 미리 기록하지 않으며 실제 게시 URL을 운영자가 확인해야 완료합니다.

## 현재 제한

- 캠페인은 채널 공통 이미지 1장과 본문 1개를 사용합니다. 채널별 서로 다른 본문·이미지는 아직 없습니다.
- Threads 본문은 공통 본문이 500자를 넘으면 게시할 수 없습니다.
- 밴드는 캠페인별 대상이 아니라 연결 설정의 기본 밴드 1곳을 사용합니다.
- 캐러셀, 영상·릴스·스토리, 예약 게시, 성과 지표 수집은 포함하지 않습니다.
- SNS UI 변경 시 Playwright 선택자 유지보수가 필요합니다.
- AI worker는 한 번에 한 작업만 처리합니다.
- 광고 이미지는 로컬 템플릿 기반이며 사진형 완전 생성 이미지는 자동화 범위에 없습니다.
- ChatGPT 로그인이 만료되거나 구독 사용량 제한에 걸리면 대기 요청을 나중에 다시 실행해야 합니다.

## 다음 실검증 순서

1. **연결 · 채널 → ChatGPT로 Codex 로그인** 후 저장된 동향 요청 한 건 실행
2. 테스트 캠페인에서 카피와 로컬 PNG 자동 저장 확인
3. **연결 · 채널 → Threads → 전용 브라우저 로그인** 후 테스트 캠페인 게시
4. 게시할 밴드 홈 URL 저장, 밴드 로그인 후 테스트 캠페인 게시
5. 두 번째 네이버 스마트스토어를 실제 키로 추가해 개별/전체 수집 비교
