# 설정과 실행

화면을 따라 작업하는 절차는 [상세 사용 설명서](user-guide.md), 오류별 조치는 [상황별 문제 해결](troubleshooting.md)에 있습니다. 이 문서는 설치·설정과 실행 명령을 다룹니다.

GitHub 반영, 새 PC의 소스 다운로드, 최초 계정 연결을 순서대로 진행하려면 [GitHub 등록과 다른 PC 설치](new-pc-installation.md)를 기준으로 합니다.

## Windows 실행

1. Node.js 24 이상을 준비합니다. 개발에 사용한 버전은 24.15.0입니다.
2. `codex_version` 폴더에서 `npm install`을 한 번 실행합니다. 공식 Codex SDK와 Playwright 실행 모듈이 함께 설치됩니다.
3. Windows 탐색기에서 `start.bat`을 더블클릭합니다. 기본 브라우저에 로컬 화면이 열립니다. SNS 자동 게시를 쓸 때는 이 실행 방법을 사용해야 전용 브라우저가 외부 사이트에 접속할 수 있습니다.
4. Codex에서 사용하려면 “codex_version 운영 화면을 내부 브라우저로 열어줘”라고 요청합니다.

기본 주소는 `http://127.0.0.1:4317/`입니다. 루트 프로젝트의 기존 3000번 포트와 별도로 실행합니다. 같은 앱이 실행 중이면 런처가 해당 화면을 재사용합니다. `stop.bat`은 실행 기록의 PID·폴더와 현재 서버가 일치하는지 확인하고 로컬 API에 정상 종료를 요청합니다. 진행 중인 요청은 완료 후 닫히며, 전역 Node 프로세스를 종료하지 않습니다.

서버 창은 숨겨지고 로그는 `data/runtime`에 저장됩니다. 실시간으로 보려면 루트의 `logs.bat`을 실행하거나 PowerShell에서 `npm run logs`를 사용합니다. 자세한 파일 구분과 채널 필터는 [로그 확인](logs.md)을 참고합니다.

개발 명령은 `npm run dev`(서버 코드 변경 감지), `npm start`(일반 실행)입니다. Codex 도구의 제한된 터미널에서 시작한 서버는 SNS 전용 브라우저도 같은 네트워크 제한을 물려받을 수 있으므로 실제 SNS 로그인·게시 운영에는 탐색기에서 실행한 `start.bat`을 사용합니다. 브라우저 파일 수정은 새로고침으로 반영합니다. `.env`의 PORT나 기존 호환 연결을 직접 편집하면 서버를 재시작하세요. 화면에서 추가·수정한 네이버 연결과 밴드 대상 주소는 현재 서버에 즉시 적용됩니다.

재부팅 후에는 서버도 다시 시작해야 합니다. 탐색기에서 `C:\dev\dev\d2c\codex_version\start.bat`을 실행한 뒤 기존 캠페인을 선택합니다. 저장된 상품·캠페인·이미지는 유지되며, 매번 의존성을 다시 설치하거나 키를 다시 입력할 필요는 없습니다. 현재 자동 시작은 등록하지 않았습니다. 화면의 **새로고침**은 서버를 실행하거나 네이버 상품을 수집하는 기능이 아닙니다.

설치와 최초 연결 이후 반복 운영은 [매일 운영 순서](daily-operation.md)를 따릅니다. **오늘 할 일** 화면이 미완료 게시 기록과 다음 행동을 먼저 표시합니다.

## 네이버

**연결 · 채널 → 네이버 스토어 추가**에서 아래 항목을 입력하고 저장합니다. 필요한 만큼 연결을 반복해서 추가할 수 있습니다.

- 스토어 이름: 운영 화면에서 표시할 이름
- 스토어 식별자: `my-store` 같은 내부 구분값. 서로 다른 실제 계정에는 다른 값을 사용하세요.
- Client ID와 Client Secret: 네이버 커머스 API 센터 발급 값

네이버 애플리케이션에 상품·주문 조회 권한과 현재 PC의 실제 아웃바운드 IP를 등록해야 합니다. 유동 IP가 변경되면 등록을 갱신해야 합니다. 회사 VPN 등을 켜면 네이버가 보는 IP도 달라질 수 있습니다.

설정 저장과 실제 연동 성공은 다릅니다. 해당 스토어의 **지금 수집** 또는 **전체 스토어 수집** 결과를 확인하세요. 키가 없거나 인증에 실패하면 오류를 표시하며 샘플 데이터로 대체하지 않습니다. 다른 프로젝트의 키를 자동으로 읽어 오지 않습니다. 기존 codex_version 0.2.x의 `.env` 단일 연결만 첫 시작 때 DB로 이관합니다.

초기에는 최근 24시간을 수집합니다. 이후에는 저장된 마지막 성공 위치에서 이어받습니다. 명시적 과거 조회:

```powershell
node src/cli.mjs sync orders --store my-store --from 2026-09-01T00:00:00+09:00
```

네이버가 조회 기간을 거절하면 허용된 범위로 조정합니다. 수집기는 여러 구간으로 나누지만 공급자의 보관 기간 제한을 없애지는 못합니다.

## 데이터 보관

| 경로 | 내용 |
|---|---|
| `.env` | 포트와 기존 단일 네이버 연결의 호환 입력. Git 제외 |
| `data/d2c.sqlite` | 네이버 연결·SNS 설정·상품·주문 요약·캠페인·작업·게시 이력 |
| `data/assets/` | 사용자가 추가하거나 Codex가 제작한 게시 이미지 |
| `data/work/` | Codex 제작 요청·결과 JSON과 작업 파일 |
| `data/exports/` | 검토 버전별 이미지·본문·캠페인 파일 |
| `data/backups/` | 앱이나 CLI로 만든 SQLite 백업 |
| `data/runtime/` | 런처 PID와 서버 로그 |
| `data/ai-status.json` | 현재 Codex 로그인·제작 worker 상태 |
| `data/ai-workspace/` | SDK가 작업 디렉터리로 사용하는 로컬 빈 작업 공간 |
| `data/instagram-profile/` | 기존 Instagram 전용 로그인 프로필 |
| `data/threads-profile/` | Threads 전용 로그인 프로필 |
| `data/band-profile/` | 네이버 밴드 전용 로그인 프로필 |

DB 백업은 `node src/cli.mjs backup` 또는 설정 화면의 버튼으로 생성합니다. 실행 중인 DB는 SQLite backup API를 사용하므로 WAL의 미반영 데이터를 놓치지 않습니다. 사진까지 보존하려면 `data/assets`도 함께 보관하세요. 전체 복구는 서버·수집기를 종료하고 백업 DB와 이미지 폴더를 복원하는 방식입니다. 기존 데이터를 덮어쓰기 전 현재 폴더를 별도 보관하세요.

이 앱은 단일 PC 사용자용입니다. DB에는 네이버 연결 자격증명이 포함되며 DB·`.env`의 디스크 암호화는 제공하지 않으므로 OS 계정 접근 권한으로 보호합니다. 키는 화면 상태 API에 반환하지 않습니다. 웹 포트의 외부 공개나 공유 PC 운영을 전제로 하지 않습니다.

## 예약 실행

예약 작업은 아직 등록하지 않았습니다. 주문 수집이 필요하면 Windows 작업 스케줄러에 다음처럼 등록할 수 있습니다.

- 프로그램: `node.exe`의 실제 절대 경로
- 인수: `"C:\dev\dev\d2c\codex_version\src\cli.mjs" sync orders`
- 시작 위치: `C:\dev\dev\d2c\codex_version`
- 중복 실행: 새 인스턴스 시작 안 함

PC가 꺼져 있거나 잠든 동안의 실행은 보장되지 않습니다. 재실행 시 가능한 조회 범위 안에서 이어받습니다. 네이버 IP가 등록된 PC에서 실행해야 합니다.

아침 운영 요약은 사용자가 요청하면 Codex 예약 작업으로 등록할 수 있습니다. 로컬 데이터에 접근하는 Codex 예약 작업은 PC와 Codex 앱이 실행 중이어야 합니다.

## 오류 처리

- 연결 준비: 키 미등록 상태입니다. 수동 상품 등록은 사용 가능합니다.
- IP 거부: 네이버 센터의 호출 IP를 실제 출구 IP와 맞춥니다.
- 네트워크 접근 차단(EACCES/EPERM): 서버 실행 환경의 외부 통신 권한을 확인합니다. Codex의 제한된 실행 환경에서 시작한 서버라면 네트워크 접근이 허용된 실행으로 재시작하거나, Windows에서 `stop.bat` 후 `start.bat`을 직접 실행합니다. IP 등록과 별개의 문제입니다.
- 연결 시간 초과 / DNS 오류: 핫스팟·인터넷 연결 또는 DNS 상태를 확인한 뒤 다시 수집합니다.
- 이미 수집 중: 진행 중인 작업을 기다립니다. 비정상 종료 시 잠금은 최대 10분 뒤 만료됩니다.
- 다른 작업에서 수정됨: 새로고침 후 최신 내용에 다시 적용합니다.
- 검토 버튼 비활성: 본문과 게시 이미지가 모두 저장되어야 합니다.
- 게시 주소 오류: 프로필 주소가 아니라 채널별 실제 게시물 주소를 입력합니다. 형식은 [SNS 채널 안내](social-channels.md)를 참고합니다.
- 이미지 생성 한도: Codex 사용량을 확인하고 초안 상태로 보존합니다. 다른 유료 API로 자동 전환하지 않습니다.
