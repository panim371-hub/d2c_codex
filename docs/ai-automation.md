# 구독 Codex AI 연결과 화면 실행

[문서 목록](README.md) · [매일 운영 순서](daily-operation.md) · [문제 해결](troubleshooting.md)

0.5.0부터 동향 조사와 광고 제작은 운영 화면의 버튼으로 실행할 수 있습니다. 앱은 공식 `@openai/codex-sdk`를 로컬 worker에서 실행하며 Codex CLI의 ChatGPT 로그인을 공유합니다. OpenAI API 키는 사용하지 않습니다.

## 최초 1회 연결

1. `start.bat`을 실행하고 [운영 화면](http://127.0.0.1:4317)을 엽니다.
2. **연결 · 채널 → 구독 Codex AI**로 이동합니다.
3. **ChatGPT로 Codex 로그인**을 누릅니다.
4. 열린 브라우저에서 이 PC의 ChatGPT 계정으로 로그인하고 Codex 접근을 승인합니다.
5. 운영 화면으로 돌아와 **상태 다시 확인**을 누릅니다.
6. 상단에 **구독 AI 연결**이 보이면 준비가 끝났습니다.

로그인은 Codex CLI의 사용자 영역에 보관되므로 앱 재시작이나 PC 재부팅 때마다 반복하지 않습니다. 로그인이 만료되거나 다른 Windows 사용자로 실행하면 다시 연결합니다.

**API 키 로그인**이 표시되면 자동 실행 버튼이 차단됩니다. 이 앱은 별도 API 요금을 피하기 위해 ChatGPT 로그인만 자동 작업에 사용합니다. 터미널에서 `node node_modules/@openai/codex/bin/codex.js logout`을 실행한 뒤 화면에서 ChatGPT 로그인을 다시 진행합니다.

## 동향 조사 실행

1. **오늘 할 일 → 최근 동향에서 광고 기회 찾기**에서 오늘, 이번 주 또는 키워드 조사를 선택합니다.
2. ChatGPT 로그인이 준비된 상태면 요청 저장과 동시에 AI worker가 시작됩니다.
3. 화면에는 **조사 중 → 저장 중 → 완료** 상태가 표시됩니다. 다른 화면으로 이동해도 작업은 계속됩니다.
4. 완료되면 결과가 자동으로 다시 읽힙니다. 필요하면 오른쪽 위 **새로고침**을 누릅니다.
5. 출처 URL, 발행일, 활용 기간, 주의 사항을 확인한 뒤 캠페인으로 전환합니다.

동향 조사에는 실시간 웹 검색을 사용합니다. 판매 상품의 가격·구성 같은 사실은 로컬 상품 데이터에서 가져오고, 뉴스의 주장을 상품 효능처럼 표현하지 않도록 결과를 분리합니다.

## 광고 카피와 이미지 실행

1. 캠페인 제목, 제작 방향, 게시 채널을 입력합니다.
2. **AI 광고 제작 시작**을 누릅니다. 미저장 편집은 먼저 저장되고 현재 revision의 제작 요청이 등록됩니다.
3. Codex가 상품 사실을 바탕으로 본문과 시안을 구조화된 결과로 만듭니다.
4. 로컬 Chromium이 상품 사진과 AI가 만든 짧은 문구로 1080×1350 PNG를 렌더링합니다.
5. 결과가 현재 캠페인에 저장되면 카피 시안과 이미지 미리보기가 자동으로 나타납니다.
6. 실제 판매 내용과 대조한 뒤 **검토 완료로 표시**합니다.

Threads가 선택된 캠페인은 AI에게 본문과 시안을 각각 500자 이하로 작성하도록 요청합니다. 그래도 최종 저장과 검토 단계에서 길이를 다시 검사합니다.

## 대기 작업 재개

로그인 전에 요청을 저장했거나 PC가 꺼져 작업이 중단됐다면 데이터는 남아 있습니다.

1. 앱을 다시 실행합니다.
2. **연결 · 채널**에서 AI 연결 상태를 확인합니다.
3. **오늘 할 일**의 최상단 **AI 조사 시작** 또는 **AI 광고 제작 시작**을 누릅니다.
4. 여러 건이 있으면 **연결 · 채널 → 대기 작업 실행**으로 한 건씩 처리합니다.

현재 worker는 한 번에 AI 작업 한 건만 실행합니다. 작업 중에는 관련 버튼이 비활성화되고 완료 후 다음 건을 실행할 수 있습니다.

## 진행 상태와 로그

화면 상단과 **연결 · 채널**에서 현재 상태를 확인합니다. 자세한 실행 기록은 `logs.bat`에서 `AI` 표시로 볼 수 있습니다. PowerShell에서는 다음 명령을 사용합니다.

```powershell
Set-Location -LiteralPath 'C:\dev\dev\d2c\codex_version'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\logs.ps1 -Channel ai
```

상태 파일은 `data/ai-status.json`, 로그는 `data/runtime/ai-worker.log`에 저장됩니다. 인증 토큰, 네이버 Client Secret, SNS 쿠키는 프롬프트나 worker 환경으로 전달하지 않습니다.

## 수동 처리 예비 절차

구독 사용량 제한, 로그인 장애 또는 SDK 장애가 있을 때만 **수동 처리 방법**을 펼쳐 문장을 복사하고 Codex 데스크톱 대화에서 처리합니다. 기존 CLI의 `campaign apply`, `trend apply` 절차도 유지됩니다. 화면 자동 실행이 정상일 때는 채팅창을 오갈 필요가 없습니다.

## 현재 범위

- 캠페인 제작은 별도 웹 검색 없이 저장된 상품 사실과 제작 방향을 사용합니다.
- 동향 조사는 최신 출처 확인을 위해 네트워크를 사용합니다.
- 생성 이미지는 로컬 HTML 템플릿 렌더링입니다. 사진형 완전 생성 이미지는 현재 자동 worker 범위에 포함하지 않습니다.
- 진행 중 PC를 재부팅하면 작업은 **중단됨**으로 바뀌며 같은 대기 작업을 다시 실행할 수 있습니다.
