# Instagram 자동 게시 설정과 사용

[문서 목록](README.md) · [전체 SNS 채널 안내](social-channels.md) · [문제 해결](troubleshooting.md)

이 문서는 실제 계정으로 검증된 Instagram 흐름의 상세 안내입니다. Threads와 네이버 밴드는 [SNS 채널 로그인과 게시](social-channels.md)를 참고합니다.

## 동작 방식

`codex_version`은 Meta API 키 없이 Playwright 전용 브라우저를 열어 Instagram 웹 게시 화면을 조작합니다. 최초 로그인 후 세션은 다음 전용 폴더에 저장됩니다.

```text
C:\dev\dev\d2c\codex_version\data\instagram-profile\
```

개인 Chrome·Edge 프로필이나 `local_version`의 세션을 복사하지 않습니다. 비밀번호와 추가 인증 코드는 앱에 입력하지 않고 열린 Instagram 화면에서 직접 처리합니다. 캠페인의 이미지와 본문은 검토 완료된 최신 버전만 사용합니다.

## 최초 1회 로그인

1. `start.bat`으로 앱을 실행합니다.
2. **연결 · 채널 → SNS Playwright 연결 → Instagram**으로 이동합니다.
3. **전용 브라우저 로그인**을 누릅니다.
4. 별도 Chromium·Edge·Chrome 창이 열리면 게시할 Instagram 계정으로 로그인합니다.
5. 추가 인증이나 로그인 정보 저장 질문이 나타나면 브라우저에서 직접 처리합니다.
6. 앱이 로그인 쿠키를 감지하면 상태가 **완료**로 바뀌고 전용 창이 닫힙니다.

상태는 약 2초 간격으로 갱신됩니다. 창을 닫았거나 10분 안에 로그인하지 못했다면 **실패**가 표시되며 로그인 버튼으로 다시 시작할 수 있습니다.

다음 사용부터는 저장된 세션이 유효하면 이 로그인 단계를 반복하지 않습니다. 앱에 **로그인 필요**가 표시되거나 Instagram이 추가 인증을 요구할 때만 다시 로그인합니다.

## 캠페인 자동 게시

1. 마케팅 스튜디오에서 캠페인의 이미지·본문과 실제 상품 정보를 확인합니다.
2. 상품 사실 확인란에 체크하고 **검토 완료로 표시**를 누릅니다.
3. 게시할 Instagram 계정이 전용 브라우저에 로그인돼 있는지 확인합니다.
4. **현재 캠페인의 이미지와 본문이 로그인된 Instagram 계정에 즉시 공유되는 것을 확인했습니다.**에 체크합니다.
5. **Instagram 게시**를 누릅니다.
6. 전용 브라우저가 열리면 자동으로 만들기 → 이미지 첨부 → 자르기·필터 다음 → 본문 입력 → 공유하기를 진행합니다.
7. 앱에 **완료**가 표시되면 실제 Instagram 피드에서 이미지와 본문을 확인합니다.
8. 게시물을 열어 `/p/…/` 주소를 복사하고 Instagram 카드의 **실제 게시물 주소**에 입력합니다.
9. 실제 게시 확인란에 체크하고 **주소 기록**을 누릅니다.

자동 게시 확인란은 실제 공유 버튼 실행에 대한 확인입니다. **주소 기록**은 앱의 Instagram publication을 만드는 별도 단계입니다. 캠페인에서 다른 채널도 선택했다면 모든 채널 주소를 기록할 때 `PUBLISHED`가 됩니다.
공유 완료 메시지가 확인된 캠페인은 게시 버튼이 잠깁니다. 실제 게시물 주소를 기록하기 전에 같은 캠페인을 다시 자동 게시하지 않습니다.

## 자동화 상태

| 상태 | 의미와 할 일 |
|---|---|
| 로그인 필요 | 전용 브라우저 로그인 실행 |
| 브라우저 여는 중 | 새 창이 뜰 때까지 잠시 대기 |
| 로그인 대기 | 열린 창에서 로그인·추가 인증 완료 |
| 게시 준비 중 | 이미지 첨부와 본문 입력 진행 중 |
| 게시 중 | 공유 요청을 보냈으므로 버튼을 다시 누르지 않음 |
| 완료 | 실제 피드를 확인하고 게시 주소 기록 |
| 실패 | 피드에 이미 게시됐는지 먼저 확인한 뒤 오류에 따라 재시도 |
| 실행 중단 | 재부팅이나 프로세스 종료가 있었음. 피드 확인 후 다시 실행 |

## 직접 게시 대안

Instagram 화면 변경이나 보안 확인 때문에 자동화가 실패하면 검토 완료 캠페인의 **이미지 저장**과 **본문 파일 저장**을 사용합니다. Instagram에서 직접 만들기 → 게시물로 업로드하고, 완료 후 같은 방식으로 게시 주소를 기록합니다.

## 제한 사항

- 이미지 1장의 일반 피드 게시를 대상으로 합니다. 캐러셀·스토리·릴스 영상·예약 게시는 포함하지 않습니다.
- Instagram 웹의 버튼 이름이나 화면 구조가 바뀌면 선택자를 수정해야 할 수 있습니다.
- 세션은 영구 보장되지 않습니다. Instagram이 만료하거나 보안 확인을 요구하면 다시 로그인합니다.
- 자동화가 공유 버튼을 누른 뒤 완료 메시지를 받지 못한 경우에도 실제 게시가 성공했을 수 있습니다. 중복 방지를 위해 재시도 전에 계정을 확인합니다.
- `data` 폴더를 다른 PC로 복사해도 Instagram이 새 기기로 판단해 재인증을 요구할 수 있습니다.
- 전용 브라우저 창을 동시에 여러 개 실행하지 않습니다. 실행 중 상태에서는 새 로그인·게시 요청이 차단됩니다.
