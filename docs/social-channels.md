# SNS 채널 로그인과 게시

새 캠페인 화면에서는 **전용 브라우저 로그인이 완료된 채널만 선택할 수 있습니다.** 미연결 채널은 `로그인 필요`로 표시되고 체크박스가 비활성화됩니다. 로그인 완료 후 캠페인 창을 다시 열면 선택할 수 있습니다.

[문서 목록](README.md) · [매일 운영 순서](daily-operation.md) · [Instagram 상세 설정](instagram-setup.md)

이 앱은 공식 게시 API 대신 로컬 PC의 Playwright 전용 브라우저를 사용합니다. 채널별 로그인 프로필과 상태 파일을 분리합니다.

| 채널 | 로그인 프로필 | 게시 대상 | 본문 기준 |
|---|---|---|---|
| Instagram | `data/instagram-profile` | 로그인한 계정의 일반 피드 | 최대 2,200자 |
| Threads | `data/threads-profile` | 로그인한 Threads 계정 | 최대 500자 |
| 네이버 밴드 | `data/band-profile` | 설정한 밴드 홈 | 앱 공통 최대 2,200자 |

Threads 웹은 글과 사진 게시를 지원하고 현재 기본 웹 주소는 `threads.com`입니다. 네이버 밴드도 PC 웹에서 게시글 작성이 가능합니다. 실제 버튼 구조는 서비스 업데이트나 계정 상태에 따라 달라질 수 있습니다.

## 최초 로그인

1. 앱의 **연결 · 채널**을 엽니다.
2. 사용할 채널 카드에서 **전용 브라우저 로그인**을 누릅니다.
3. 열린 브라우저에서 직접 로그인과 추가 인증을 완료합니다.
4. 앱 상태가 **완료**로 바뀌는지 확인합니다.

비밀번호와 인증 코드는 로컬 앱에 입력하지 않습니다. Instagram의 기존 로그인 경로는 0.2.x와 같아 이전 세션을 그대로 사용합니다. Threads와 밴드는 새 프로필이므로 최초 한 번 로그인해야 합니다.

## 밴드 게시 대상 설정

밴드는 로그인 계정이 여러 밴드에 가입할 수 있으므로 게시 대상 주소가 필요합니다.

1. 브라우저에서 게시할 밴드 홈을 엽니다.
2. 주소가 `https://band.us/band/숫자` 형식인지 확인해 복사합니다.
3. **연결 · 채널 → 네이버 밴드 → 게시할 밴드 홈 주소**에 붙여넣습니다.
4. **밴드 주소 저장**을 누릅니다.

프로필 주소나 개별 게시물 주소를 대상으로 저장하지 않습니다. 캠페인 게시 결과에는 게시 후의 `https://band.us/band/숫자/post/숫자` 주소를 기록합니다.

## 캠페인 게시

1. 새 캠페인에서 게시할 채널을 선택합니다.
2. 카피와 이미지 저장 후 검토를 완료합니다.
3. 채널 카드에서 로그인 계정과 현재 콘텐츠를 확인합니다.
4. 즉시 게시 확인란을 체크하고 채널의 **게시** 버튼을 누릅니다.
5. 완료가 표시되면 실제 채널에서 게시물을 확인합니다.
6. 실제 게시물 URL과 확인 체크를 입력해 **주소 기록**을 누릅니다.

한 캠페인에서 여러 채널을 선택하면 게시 기록도 여러 개입니다. 첫 채널의 주소를 기록해도 캠페인은 **게시 준비**로 남고, 선택한 채널을 모두 기록하면 **게시 완료**로 바뀝니다. 첫 게시 기록 뒤에는 이미 게시한 내용과 로컬 확정본의 불일치를 막기 위해 콘텐츠 편집을 잠급니다.

## 채널별 제약

### Instagram

이미지 1장의 일반 피드 게시를 자동화합니다. 만들기, 이미지 첨부, 자르기·필터 다음, 본문, 공유 완료 메시지 순서입니다. 실제 계정 게시까지 검증된 채널입니다.

### Threads

이미지 1장과 500자 이하 본문을 새 글 작성기에 입력합니다. 500자를 넘으면 게시 전에 앱과 worker가 중단합니다. Threads가 작성기를 모달이나 홈 화면의 인라인 영역으로 표시하는 두 경우를 모두 지원합니다. 게시 주소는 `/@계정/post/코드/`와 Threads 공유 메뉴가 제공하는 `/share/코드/` 형식을 모두 기록할 수 있습니다.

### 네이버 밴드

설정한 밴드 홈에서 글쓰기, 본문, 이미지 첨부, 게시 단계를 수행합니다. 해당 밴드에 글쓰기 권한이 있어야 합니다. 0.3.0에는 어댑터와 설정 검증이 구현됐지만 이 PC 계정의 실제 로그인·게시 검증은 아직 수행하지 않았습니다.

## 실패 또는 중단

공유·게시 버튼을 누른 뒤 오류가 났다면 자동으로 다시 실행하지 않습니다. 실제 피드나 밴드에서 게시 여부를 먼저 확인해야 중복 게시를 피할 수 있습니다. 게시되지 않은 것이 확인됐을 때만 다시 실행합니다. 화면 구조가 달라졌다면 `data/runtime/<채널>-worker.log`의 비밀정보가 아닌 오류 문구를 바탕으로 선택자를 보완합니다.

자동화가 어려우면 **이미지 저장**과 **본문 저장**으로 직접 게시하고, 실제 URL은 동일하게 기록합니다.
